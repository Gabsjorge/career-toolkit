# Platform Engineer, Northwind Cloud

Northwind Cloud helps teams ship software faster. We are looking for a platform engineer to join our delivery team. You will work with our developers and make sure that the pipelines they use are fast and safe.

What you will do
- Own the CI pipelines for tests and deploys.
- Manage cloud infrastructure with Terraform.
- Run container workloads on AWS.

What we ask
- Experience with CI/CD and GitHub Actions.
- Experience with Terraform.
- Experience with AWS.
- Experience with Docker.

Nice to have
- Code review habits in a larger team.
- Fully remote work is possible, and we ask that you are comfortable with it.
