# Desenvolvedor(a) Java, Wingtip Seguros

A Wingtip Seguros é uma empresa de seguros que está a modernizar os seus sistemas. Estamos à procura de um desenvolvedor Java para a nossa equipa de apólices. Você vai trabalhar com os nossos analistas e migrar serviços antigos para microsserviços.

O que você vai fazer
- Desenvolver serviços em Java com Spring.
- Escrever consultas SQL para os relatórios.
- Desenhar microsserviços novos.

O que pedimos
- Experiência com Java.
- Experiência com Spring.
- Experiência com microsserviços.
- Bons conhecimentos de SQL.

Diferencial
- Experiência com MySQL.
- Inglês fluente.
